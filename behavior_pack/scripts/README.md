# Scripts

Planned Script API entrypoint:

- `main.ts`

Planned modules:

- `systems/` for shared runtime systems.
- `entities/` for entity state helpers.
- `economy/` for trade/economy script support if needed.
- `military/` for soldier, mercenary, ownership, banner, and equipment systems.
- `population/` for minimal population support only if vanilla behavior is insufficient.
- `raids/` for random Pillager attack scheduling and scaling.
- `worldgen/` for research-backed world generation support if needed.

Do not add hard-coded player names. Keep gameplay constants centralized once implementation starts.
