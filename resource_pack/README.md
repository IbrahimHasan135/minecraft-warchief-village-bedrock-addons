# Resource Pack

This folder will contain the visual/audio/text side of the Warchief Village Add-On.

Planned content:

- `manifest.json` after the target Bedrock version is selected.
- `entity/` for client entity definitions.
- `models/entity/` for Bedrock entity geometry exported from Blockbench.
- `textures/entity/` for Soldier and Mercenary skins.
- `textures/items/` for Military Token and Command Banner icons.
- `animations/` for humanoid animation files.
- `animation_controllers/` for animation state selection.
- `render_controllers/` for equipment/armor visual states.
- `attachables/` if custom held/equipment visuals require them.
- `texts/` for localization such as `en_US.lang`.
