# Entity Textures

Put custom entity textures here.

Recommended first assets:

- `villager_soldier.png`
- `mercenary.png`
- `armor_iron.png`
- `armor_diamond.png`
- `armor_netherite.png`

Prototype direction:

- Start texture-first using a Pillager/Illager-compatible UV layout.
- Villager Soldier should read as a village guard/militia.
- Mercenary should read as a hired wanderer/fighter.
- Keep both compatible with the same base model until custom visuals are truly needed.

Placeholder textures are acceptable for prototype phases.
