# Animations

Prototype direction:

- Try vanilla Pillager/Illager-compatible animations first.
- Reuse existing idle, walk, attack, and crossbow-style hold/fire animations if the target Bedrock version allows stable references.
- If direct references fail, add local animation files here only for the animations that are actually needed.

Do not create custom animation polish before the entity prototype can spawn, render, move, and attack.
