# Soldier References

Use this folder for Villager Soldier concept art, Blockbench source files, draft skins, or notes.

Current prototype direction:

- Use a Pillager/Illager-compatible base first.
- Prepare a custom texture before creating a custom model.
- The Soldier should look like a recruited village guard, not a hostile Pillager.
- Keep the UV layout compatible with the base model used by the Resource Pack.

Runtime geometry should eventually go to `resource_pack/models/entity/`.
Runtime textures should eventually go to `resource_pack/textures/entity/`.
